# CodeAlpha Student Grade Tracker

## Description
Student Grade Tracker is a Java console-based application used to manage and analyze student grades.

## Features
- Add student name and grade
- Display all students
- Calculate average score
- Find highest and lowest scores
- Generate a complete summary report
- Validate grades between 0 and 100

## Technologies Used
- Java
- ArrayList
- Scanner
- Loops
- Conditional Statements
- Switch Case
- Methods
